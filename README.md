# SpellQuest

A fifth-grade spelling adventure where each correctly rebuilt word restores part of a fantasy kingdom.

## Play

https://fidgetbot.github.io/SpellQuest/

## Activities

- Rune Scramble: put shuffled letters in order
- Missing Runes: supply missing letters
- Spot the Spell: choose the correctly spelled word

Progress is saved locally in the browser. The game has no accounts, advertisements, or external services.
